💻 Projeto Mario Kart (DIO)

Projeto desenvolvido durante a formação da DIO.

Simulação de corrida estilo Mario Kart usando JavaScript, onde personagens competem em uma corrida com resultados definidos de forma aleatória.

Os personagens foram definidos manualmente (ex: Lilo e Stitch) e a lógica da corrida calcula o vencedor com base em atributos como velocidade e aleatoriedade.

🧠 Melhorias adicionadas
Personagens personalizados (ex: Lilo e Stitch)
Estrutura de corrida mais organizada
Exibição mais clara dos resultados no console

🎯 Objetivo do projeto
Praticar lógica de programação com JavaScript
Entender conceitos básicos de simulação e aleatoriedade
Melhorar organização de código em projetos simples
